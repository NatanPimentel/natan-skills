# {{BRAND}} legibility patterns

## Feedback signal

Treat user feedback such as “texto minúsculo”, “quebrado”, “a capa ocupa pouco espaço” or an example of a detached period as a renderer and copy QA issue, not a cosmetic preference only.

## Cover target

- Frame: 1080×1350.
- Target H1 visual mass: roughly 40% of useful frame area.
- A cover H1 that is visibly around 20% is underweighted even if it technically fits.
- Prefer a strong multi-line block with adequate dark overlay to a timid headline with excess empty image area.

## All-type slides

- Dense explanatory paragraphs become unreadable if a fit routine shrinks body text.
- Compress to a single sharp proposition plus a short explanation and preserve the supporting bullets.
- Avoid a `<strong>` phrase ending immediately before punctuation when it creates a line-wrap artifact. Include the punctuation inside the element or rephrase.

## Selective revision examples

- Cover-only feedback for three posts → export each `slide-01.jpg` only.
- Feedback for one named text slide → edit its copy/layout and export only that slide.
- Deliver the changed files alone, not another full set of 30 images.
